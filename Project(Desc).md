## 📌 Project Description

SkillNect is an AI-powered career development platform that helps students and job seekers build resumes, prepare for interviews, and follow structured career roadmaps in one place.

It integrates multiple features into a single system to simplify career preparation and improve job readiness.

### Core Functionalities

- **Resume Builder**  
  Users can enter personal details, education, projects, skills, and certifications to generate a professional resume in PDF format.

- **Interview Preparation**  
  Users can paste their resume and/or job description. The system analyzes the input and generates relevant interview questions and guidance.

- **Career Roadmap**  
  Users can enter a career goal (e.g., Java Developer), and the system provides a structured roadmap with topics and recommended learning resources.

- **Profile Management**  
  Stores user information and allows saving selected roadmaps for future reference.

### Outcome

- Simplifies resume creation  
- Provides guided interview preparation  
- Helps users follow a clear learning path  
- Improves overall career readiness
